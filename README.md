# Glass Dashboard

Προσωπικό dashboard έργων (Η εταιρία μου · Συνεργαζόμενη εταιρία · Hobbies & Σπίτι) για Mac και iPhone.

- Η εφαρμογή είναι μόνο κώδικας. **Κανένα έργο δεν αποθηκεύεται εδώ.**
- Τα έργα αποθηκεύονται στο ιδιωτικό repository `dashboard-data` (`projects.json`) και διαβάζονται/γράφονται από τον browser με προσωπικό GitHub token που μένει μόνο στη συσκευή.
- Φιλοξενία: GitHub Pages από το `main`.
